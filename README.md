# PyTorch Deep Learning Demonstrations

A collection of small demonstrations for learning and experimenting with neural network architectures using **PyTorch**.

This project is the PyTorch counterpart to a sister project using TensorFlow: **[TensorFlow Deep Learning demonstrations](https://github.com/feathered-songster/Deep-Learning-Demonstrations-TensorFlow)**.

## Running

The project is intended to run in Docker. Start the environment with:

```bash
docker compose up --build
```

JupyterLab will be available at `http://localhost:8888`.The access token can be found in the container output when started.
